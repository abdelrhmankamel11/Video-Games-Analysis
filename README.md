## 📌 Project Overview

This project analyzes video game sales data using Power BI to understand global market trends, regional sales performance, and publisher performance.

The dashboard provides insights into how video game sales vary across different regions, genres, platforms, and publishers.

## 🎯 Project Objectives

- Analyze global video game sales trends over time.
- Identify the best-selling video game titles.
- Compare sales performance across different regions.
- Analyze sales distribution by genre and publisher.
- Understand regional differences in gaming market performance.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- Data Cleaning & Transformation
- Data Visualization
